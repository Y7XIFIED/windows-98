Welcome to **Windows 98 - Haunted Edition**! 👻 Step back into 1998 with this highly authentic, entirely web-based recreation of the classic operating system. But beware... this isn't the Windows 98 you remember. Deep within the code, something sinister is lurking. From haunted messenger chats to panic-inducing file deletions, drifting windows, and the terrifying Blue Screen of Death roulette, this OS has a mind of its own. It's the ultimate nostalgic trip mixed with an interactive digital nightmare! Can you survive the nostalgic terror?

## 🚀 Live Website
Experience the fully interactive website live here: https://win98ie.vercel.app

## 🎮 How to Control
- **Booting Up:** Just open the page! Watch the authentic BIOS screen and MS-DOS boot sequence load right before your eyes.
- **Navigation:** Click on desktop icons to open applications like My Computer, Paint, or the MS-DOS Prompt.
- **Task Switcher:** Press `Spacebar + Tab` to pull up the classic OEM task switcher and cycle through your open windows.
- **The Pranks:** Explore the OS to trigger hidden haunted events! Try deleting files, getting left on "Seen" in Messenger, or opening the mysterious "DO NOT CLICK" folder... if you dare. 

## ⚙️ Installation

**Prerequisites:**
- A modern web browser (Chrome, Edge, Firefox, or Safari).

**Setup Instructions:**
1. Clone the repository:
   ```bash
   git clone https://github.com/Y7XIFIED/windows-98.git
   ```
2. Navigate to the project directory:
   ```bash
   cd windows-98
   ```
3. Open `index.html` in your favorite web browser. No local server required!

## 💻 Tech Stack
- **HTML5:** For the authentic window structures and OS layout.

- **Vanilla JavaScript:** Powers the complex window management, dragging logic, boot sequences, and all the haunted interactive events.
